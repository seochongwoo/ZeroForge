# 마찰 로그

쓰다가 불편했던 순간을 한 줄씩 적는다. 이 파일이 곧 백로그다 (P6).
날짜와 상황만 짧게. 실제 사유 내용은 적지 않는다 (P8).

- 2026-11-08 일하는 시간, 쉬는 시간에 따라 생각이 달라지는거 같다.
- 2026-11-08 내가 써야한단 생각이 있어서 키는거지 최소한의 강제 요소는 필요할 수도 있다.
- 2026-11-10 쓰고 싶다, 또는 생각이 나는 순간은 외부 요소에 달려있다. 예를 들어 음악 없이 걷기, 또는 혼자 있을 때 등등
- 2026-11-12 다시 들어가 보면, 어? 내가 이런 생각을 했었네? 싶은 순간이 많다.
- 2026-11-14 (§9-1 판단) 메모장보다 손이 먼저 가는가 → 아직 아님. 쓰고 보는 것 말고는 기능이 없어서. 다시 읽을 때의 "어?"를 키우는 이름 붙이기(Step 7)로 넘어간다
