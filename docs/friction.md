# 마찰 로그

쓰다가 불편했던 순간을 한 줄씩 적는다. 이 파일이 곧 백로그다 (P6).
날짜와 상황만 짧게. 실제 사유 내용은 적지 않는다 (P8).

### 이름 붙이기
- 2026-11-14 라벨을 일일히 클릭(터치)해서 보는건 별로 좋은 방식이 아니다.
- 2026-11-17 공모전이 끝나고 후기를 적었다. 꽤나 후련해 지는 느낌이 들었다. 내가 만들고 있는 이 어플이 잘못돼지 않았음을 또 다시 느꼈다.
- 2026-11-18 순간의 감정을 배제하고 마음속을 직시하는 것만으로도 도움이 되는 것 같다.
