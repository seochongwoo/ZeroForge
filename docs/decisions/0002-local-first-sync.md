# 0002. 로컬 우선 저장 (outbox)

- 상태: 채택
- 날짜: 2026-11-06

## 맥락

"짧은 사유"에서 한 문장이 날아가는 경험은 치명적이다. 지하철, 엘리베이터처럼 연결이 끊기는 곳에서도 쓰기는 항상 성공해야 한다.

## 결정

- 입력 중인 내용은 타이핑할 때마다 기기에 draft로 저장한다.
- 저장하면 **클라이언트가 UUID를 만들고** outbox(기기 저장소)에 넣은 뒤 입력창을 비운다. 사용자 입장에서 저장은 이 순간 끝난다.
- outbox는 앱이 열릴 때, 네트워크가 돌아올 때, 다음 저장 때 서버로 보낸다. 성공한 것만 지우고, 실패하면 순서를 지키기 위해 멈춘 뒤 다음에 다시 시도한다.
- 서버 `POST /api/entries`는 **멱등**이다. 같은 id가 이미 있으면 기존 기록을 돌려준다. 그래서 재시도해도 중복이 생기지 않는다.
- 기록 시간은 기기에서 쓴 시각(`written_at`, 시간대 포함)이고, 서버 도착 시각(`created_at`)과 분리한다. 목록은 `written_at` 기준 최신순이다.
- 목록은 서버 기록과 아직 outbox에 있는 기록을 함께 보여준다. 보내지 않은 기록은 "기기에만 저장됨"으로 표시한다. 개수는 보여주지 않는다 (P4).

## 결과

- 기기 저장소는 `@react-native-async-storage/async-storage`(웹에서는 localStorage).
- Entry는 불변이므로 동기화 충돌이 없다. 같은 id로 다른 내용이 와도 덮어쓰지 않는다.
- 여러 기기 간 draft는 공유하지 않는다. 필요해지면 friction.md에 기록된 뒤에 다시 정한다.
